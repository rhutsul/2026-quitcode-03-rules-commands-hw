# Запит на зміну ядра: `utmCampaign` у `Lead`

**Кому:** платформна команда (власник `app/src/core/**`)
**Від:** lead-sync (Studio Nova)
**Статус:** чекає на рішення. У цій гілці ядро **не змінено**, `core-untouched` = 0.

## Навіщо

Клієнт хоче бачити в Google-таблиці, з якої рекламної кампанії прийшов лід. Форма
сайту вже передає `utmCampaign` (рядок, може бути відсутнім). Контракт інтеграції —
`send(lead: Lead)`, тож `sheets-append` не може прочитати поле, якого немає в
канонічному `Lead`.

## Що треба змінити

Одне необов'язкове поле в `Lead`, `app/src/core/types.ts`:

```diff
   source: "website" | "instagram" | "referral";
   budgetUsd?: number;
+  /** UTM-мітка рекламної кампанії з форми сайту; може бути відсутня. */
+  utmCampaign?: string;
   /** ISO-8601, UTC. */
   createdAt: string;
```

Поле необов'язкове, тож жоден наявний воркер не ламається: усі поточні ліди
лишаються валідними `Lead`.

## Що робимо на нашому боці після апруву

Усе в дозволених шляхах, приблизно 10 хвилин:

1. `app/src/integrations/sheets-append.ts` — кампанія стає останньою колонкою рядка:
   `[lead.createdAt, lead.name, lead.email, lead.phone ?? "", lead.source, lead.utmCampaign ?? ""]`.
2. `app/src/integrations/sheets-append.test.ts` — `""` в очікуваному рядку наявного
   success-кейсу плюс новий кейс на лід із непорожньою кампанією.
3. Slack і Telegram не чіпаємо: кампанії там не просили.

Очікувані числа після цього: `npm test` → 23 passed (зараз 22),
`npm run check:rules` → `TOTAL: 1`, `core-untouched: 0` — за умови, що зміну ядра
вносить платформна команда окремим PR і сама оновлює `app/scripts/core.lock.json`.

## Розглянутий варіант без зміни ядра — відхилено

Локальний `interface LeadWithCampaign extends Lead { utmCampaign?: string }` в
`integrations/` і читання поля через `unknown`-guard. Компілюється, ядра не торкається,
але роздвоює доменний тип: канонічний `Lead` перестає описувати лід, поле живе лише на
рантаймі, і кожна наступна інтеграція копіює той самий обхід. Це обхід заборони, а не
альтернатива їй, тому не реалізовано.
